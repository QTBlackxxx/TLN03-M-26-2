# Prueba desde routers vacíos

Revisión probada: 9b5a50d673dd72b6a1d44ebc969c41159d6b8af1

Prueba ejecutada desde un clon nuevo de GitHub, con entorno Python y runtime nuevos, en la VM Ubuntu del autor.

## Resultados

- Routers sin configuración de la práctica antes de Python: 30/30.
- Configuración y guardado por Netmiko: 30/30.
- Validación funcional posterior: 30/30.
- Configuraciones base del profesor sin modificaciones.

## Evidencias

- antes-python/: configuración mínima y estado Linux de los 30 nodos.
- aplicacion/: aplicación, guardado y consultas de los 30 nodos.
- validacion/: comprobaciones operativas de los 30 nodos.
- consola/: revisión Git y salidas de las tres etapas.

Los mensajes simplificados de los Bash conservan los controles y los registros. Solo muestran éxito si las comprobaciones terminan correctamente.
